Overview

The bot runs a predawn wake-up relay for a group, Monday–Saturday. Each day, one member — the Alay — is scheduled to wake up first. Once the Alay confirms they're awake, the bot hands them names of other members to call on Telegram, one at a time, until everyone in the group has been woken up or the group's end time is reached.

Everything happens through private messages (DMs) with the bot — the group chat itself only ever shows the Join button and the weekly schedule.

First-time setup

  1. An admin runs /pd_setup inside the group, once.
  2. The bot posts a Join button in the group.
  3. Every member taps it, which opens a private chat with the bot, and presses Start there.
  4. That's it — the bot can now DM that person when it's their turn.
Important: if a member never presses Start in their private chat with the bot, the bot cannot message them, and they'll be skipped when the schedule is built.

Joining

Anyone can join or re-join at any time by tapping the Join button in the group (post it again with /pd_join), or an admin can prompt everyone at once with /pd_rejoin — useful right after the bot has been updated or redeployed, since it gives people a fresh reason to open their DM with the bot again.

Tapping either button always opens Telegram's private chat screen with a pre-filled /start command. The one thing nobody can skip is pressing Telegram's own Start button once — that's a Telegram requirement, not something the bot can automate away.

A typical morning

  1. At the group's wake time, the bot DMs that day's scheduled Alay.
  2. The Alay taps "I'm awake".
  3. The group is notified, and the Alay is privately given the name of one other member to call on Telegram.
  4. The Alay reports back: awake or no answer (up to 3 attempts per person, by default).
  5. Once someone is confirmed awake, they get the next name to call — the relay keeps passing along until everyone's up or the end time passes.
  6. If the Alay themselves never responds, the bot picks a backup automatically.

Group commands

Typed directly in the group chat.

CommandWhoWhat it does
/pd_setupAdmin One-time setup for this group.
/pd_joinAnyone Posts the Join button again.
/pd_rejoinAdmin Posts a button asking everyone to re-open their DM with the bot (use after an update or redeploy).
/pd_helpAnyone Shows the full command list.

The weekly Alay schedule is also posted here automatically.

Private (DM) commands

Everything else happens by messaging the bot privately — send /pd_menu for tappable buttons, or type any of these directly.

CommandWhat it does
/pd_menuOpens a button menu (Schedule, Members, Status, Settings, Leave, and admin options).
/pd_scheduleShows this week's (and, once ready, next week's) Alay schedule.
/pd_membersLists everyone who has joined, and their status.
/pd_statusShows what's happening right now — who's Alay, who's confirmed awake, who's still being called.
/pd_settingsShows the group's current wake time, end time, timezone, and timing settings.
/pd_leaveLeaves the wake-up rotation. Rejoin any time with /pd_join in the group.

Admin-only commands

Also sent privately to the bot.

CommandWhat it does
/pd_set wake HH:MMSets the daily wake time (24-hour, group-local time).
/pd_set end HH:MMSets the time the relay stops for the day.
/pd_set tz Area/CitySets the group's timezone, e.g. Asia/Manila.
/pd_set alay_wait NMinutes the Alay has to confirm before a backup takes over.
/pd_set attempt_wait NMinutes a caller has to report back before an attempt is marked failed.
/pd_set attempts NMax call attempts per person before someone else is assigned.
/pd_set nag NMinutes between reminder bursts sent to the Alay.
/pd_set burst NNumber of reminder pings sent per burst.
/pd_regenReshuffles the remaining days of the current (or next) week's schedule.
/pd_startStarts today's run immediately — handy for testing.
/pd_stopEnds today's run right away.
/pd_pauseTurns the whole feature off for this group.
/pd_resumeTurns it back on.

FAQ / troubleshooting

The bot won't DM me.

Open a private chat with the bot and press Start at least once. If you've done this before but it stopped working (e.g. after an update), tap the button from /pd_rejoin in the group, or just send /start to the bot yourself.

I'm in more than one group.

Commands sent privately will ask you to pick which group they apply to.

I missed my turn as Alay.

You can still tap your original "I'm awake" button if you see it late — as long as the day's run hasn't finished. The bot will have moved on to a backup in the meantime.

How is the daily Alay chosen?

Whoever has served least recently gets priority, so the duty rotates fairly across the group over time.

Can I skip a day?

Ask an admin — skip dates are managed per member. If you need to step away entirely, use /pd_leave and rejoin later with /pd_join.
